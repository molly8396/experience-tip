# 经验之书 · Experience Book

> **走过的路，都算数。** 每个人都是生活的行家，你的经验也可以变现。

经验之书是一本「真实可靠可执行」的人生经验库：把真人走过的路，整理成可直接照抄、可复制、可验证的经验卡片。不搬运道理，只收录「AI 查不到、真人走出来的」干货。

## 为什么是经验之书

市面上的经验内容（小红书、知乎、攻略站）大多是碎片化的"一条建议"，没人告诉你：

- 这条经验 **凭什么信**（可信度 A / B / C 三级 + 来源标注）
- 具体 **怎么落地**（步骤 + 失败排查 + 成本收益）
- 别人用过 **结果如何**（有帮助 / 不准确 / 纠错补充，反馈驱动升级）

经验之书把每条经验做成**可验证、可迭代、可追溯**的结构化卡片，让"踩过的坑"真正变成"可复制的路"。

## 四大领域

| 领域 | 覆盖 |
|---|---|
| 择路进阶 | 职场新人、考公考编、升学（专升本/考研）、跳槽转型 |
| 生活健康 | 母婴育儿、生病就医、养老照护、健康安全 |
| 智能培训 | AI 办公、个人助理、AI 创业 |
| 投资理财 | 旅游出行、日常消费、投资分析 |

## 特色

- **三级可信度**：A 级（多人验证＋数据支撑）/ B 级（多人共识或高相关案例）/ C 级（单点经验仅供参考），每条标注来源，矛盾观点并陈不掩盖
- **可复制落地**：每条经验含「怎么落地」步骤、失败排查、适用边界、成本收益
- **反馈迭代**：有帮助 / 不准确 / 纠错补充，你的反馈决定一条经验能否从"待验证"升级为"精品"
- **真人真事**：只收录真实走过的人写下的经历记录（含过程刻度、失败复盘），不做道理搬运

## 快速开始

直接打开在线体验版：[经验之书在线版](https://molly8396.github.io/experience-tip/)

在页面里你可以：

1. 浏览四大领域的经验卡片，点开看完整步骤与来源
2. 点击「说一条经验」，写下你的经历，AI 帮你整理成卡片格式，进入验证队列
3. 对每条经验反馈「有帮助 / 不准确」，或补充你的踩坑细节

## 贡献你的经验

欢迎把真实走过的路写进经验之书：

- **网页端**：使用页面内「说一条经验」功能，AI 整理 + 提交验证队列
- **GitHub Issue**：在 [Issues](../../issues) 里按以下模板提交：

```
标题：一句话概括你的经验
场景：什么情况下适用 / 不适用
步骤：1. 2. 3.（越具体越好，可含时间/温度/参数等刻度）
踩坑：哪些做法试过没用
结果：有没有可验证的结果（分数、Offer、成交、健康转归等）
```

> 原则：只写自己真实做过的事，标注适用边界，不搬运他人内容。
