本知识库收录「智能培训」领域可照抄的精品经验：官方教程路径、上手清单、自建助理方法。所有条目遵循六条判据：精确参数、刻度/变量表、结果判定、失败排查、来源证据、适用边界。

【条目 1】提示词工程三阶教程：Anthropic 官方交互式课，2.5 小时上手
来源：https://github.com/anthropics/prompt-eng-interactive-tutorial（38.4k★ 官方仓库）
适用：零基础学提示词第一课；已会用但输出不稳也建议过一遍中级章
精确步骤：
1. 先做入门章：提示词基础四要素（角色 / 任务 / 格式 / 约束）
2. 中级章学三个技巧：few-shot 给示例、思维链让它想、XML 标签结构化，每学一个在浏览器里立刻实测一次
3. 高级章学复杂任务拆解：大任务拆成多个子提示词串起来，再学输出评估与迭代
4. 全程跟着官方练习台动手改，不只看不练
刻度表：入门 45 分钟（四要素，能写清楚指令）；中级 60 分钟（示例/思维链/标签三技巧）；高级 45 分钟（任务拆解+迭代评估）
结果判定：独立写一段带角色 + 示例 + 格式约束的提示词，效果稳定复现 2 次 → 过关
失败排查：只收藏不练 = 白学；直接抄别人的复杂提示词 = 不理解结构、改不动
适用边界：英文界面需基础英文；国产模型部分技巧（标签）效果弱于 Claude

【条目 2】提示词工程入门路线：78.9k★ 官方指南怎么刷
来源：https://github.com/dair-ai/Prompt-Engineering-Guide（78.9k★）
适用：工作里天天用 AI、想系统提效的人；零基础先上【条目 1】官方三阶
精确步骤：
1. 只刷「基础概念」和「技巧」两节，跳过论文区
2. 每学 1 个技巧（零样本 / 少样本 / 思维链 / 自我一致性），立刻拿自己工作里的 1 个真实任务试一遍
3. 对照指南里的「差 vs 好」示例改自己的提示词：加示例、加角色、拆步骤
4. 保存 3 个成功 + 3 个失败案例，两周后形成自己的提示词模板库
刻度表：零样本（简单问答→摘要一条新闻）；少样本（格式控制→抽 3 个要点成表格）；思维链（推理题→让 AI 解数学题）；自我一致性（高可靠→同一题跑 3 次取多数）
结果判定：同一任务输出质量明显提升 + 手上有 6 个以上可复用模板 → 入门完成
失败排查：把论文区当入门 = 劝退；只记术语不改自己的提示词 = 等于没学
适用边界：指南偏英文与论文向，中文实操配合【条目 4】鱼皮 ai-guide 更顺

【条目 3】Claude Code 上手清单：55.2k★ 资源库怎么用
来源：https://github.com/hesreallyhim/awesome-claude-code（55.2k★）
适用：会基础命令行即可；编程经验少的先把最小任务练熟再放大
精确步骤：
1. 按官方文档装好 Claude Code CLI，先跑通 1 个最小任务（改个配置 / 跑个脚本）
2. 只读「官方文档」和「快速上手」两区，学 3 个核心命令：对话、文件操作、终端执行
3. 拿 1 个真实工作任务交给它（批量改文件名 / 写单元测试 / 重构小函数），看它怎么拆步骤
4. 报错就把它贴回去让它自己修，别急着接手；卡住 2 轮再手动接管
5. 每周至少用 1 次，一个月后把高频任务存成自定义 skill 固化
刻度表：第 1 周（装 + 最小任务→环境跑通）；第 2 周（3 个核心命令→完成 1 个真实任务）；第 3 周（报错循环调试→敢放手给复杂任务）；第 4 周（固化 skill→高频任务半自动）
结果判定：每周能独立完成 2 个以上真实编码任务 + 报错自己修通 → 上手成功
失败排查：一上来就让它写大项目 = 失控；不读官方文档直接看社区黑魔法 = 踩版本坑
适用边界：需订阅 Claude 会员或 API 额度；涉及机密代码先确认合规

【条目 4】中文 AI 学习地图：鱼皮 ai-guide 怎么刷
来源：https://github.com/liyupi/ai-guide（20.9k★ 中文）
适用：中文用户首选入口；已有基础的跳过大全直接玩教程

1. 先逛「AI 工具大全」章节，挑 3 个与你工作相关的工具逐个上手
2. Vibe Coding 零基础教程按顺序看前 5 节，跟着敲一遍（不用全看完再动手）

结果判定：两周后能独立用 AI 工具完成 1 个日常任务 + 跑通 1 个教程项目 → 入门
失败排查：收藏 50 个工具等于没用；教程只看不敲 = 白看；贪多切换工具 = 全废
适用边界：内容更新快，以仓库当前版本为准

【条目 5】自建个人 AI 助理：48.9k★ nanobot 最小路径
来源：https://github.com/HKUDS/nanobot（48.9k★）
适用：有基础命令行能力、在意数据隐私的人；纯小白先玩现成产品
精确步骤：
1. pip 安装 nanobot，按 README 跑通默认 demo（一条命令起服务）
2. 配置自己的模型 key（可接 OpenAI / DeepSeek 等），先连 1 个数据源（本地文件 / 网页）
3. 把日常 1 个重复任务写成指令（周报总结 / 邮件分类 / 会议纪要），让它跑通
4. 自托管在自己机器上，数据不出本地，按需再扩展数据源
结果判定：1 个真实任务稳定跑通 1 周 → 最小助理成立
失败排查：一上来想接全部数据源 = 配置地狱；任务写太复杂 = 模型做不好，先拆最小指令
适用边界：需自己维护运行；模型 key 有调用成本

【条目 6】AI 第二大脑：37.6k★ khoj 自托管知识问答
来源：https://github.com/khoj-ai/khoj（37.6k★）
适用：笔记多、想检索自己的资料库的人；对数据隐私敏感者友好
精确步骤：
1. Docker 一键部署 khoj，配置本地文档目录（笔记 / PDF / 网页收藏）
2. 导入资料后等索引完成，用自然语言提问，答案带出处可回查
3. 每周导入新资料（读书笔记 / 会议纪要），坚持 1 个月
4. 把高频问题存成「自动问答集」，下次直接问
刻度表：第 1 周（部署 + 导入现有资料→能问出带出处答案）；第 2 周（日常笔记持续导入→答案覆盖更全）；第 3–4 周（存高频问答集→形成个人知识库）
结果判定：1 个月后 80% 的问题能从自己资料里答出带出处 → 第二大脑成立
失败排查：导入资料太少 = 答非所问；索引没跑完就问 = 漏答；只存不问 = 白搭
适用边界：需自托管服务器 / 电脑常开；模型调用有成本

【条目 7】多模型一个入口：45.4k★ LibreChat 聚合客户端
来源：https://github.com/LibreChat-AI/LibreChat（45.4k★）
适用：多模型重度用户、想统一管理对话的人；单模型用户没必要
精确步骤：
1. Docker Compose 一键部署 LibreChat，配置 2–3 个模型 key（Claude / GPT / DeepSeek 等）
2. 日常提问统一到一个界面，按任务类型切模型（写作用 A、代码用 B、长文用 C）
3. 用 Projects 给不同项目开独立对话上下文，不串味
4. 数据自托管，对话记录自己掌控，可导出备份
刻度表：长文写作→Claude 系；代码→编程强模型；中文理解→DeepSeek 系；简单问答→任选省钱档
结果判定：一周内稳定在一个界面完成 80% 的 AI 使用 → 迁移成功
失败排查：模型 key 配太多 = 成本失控；不建 Projects = 上下文互相污染
适用边界：需自托管环境；模型按用量付费

【条目 8】Claude 提示词官方最佳实践：清晰直接 + 给示例
来源：Anthropic 官方提示词优化建议
适用：通用提示词方法论，适用 Claude / 豆包 / Coze 等主流大模型
精确步骤：
1. 把模型当才华横溢的新同事：越准确解释你想要什么，输出越好
2. Be clear and direct：指令清晰直接，不要含蓄
3. Use examples（multishot）：给 1–3 个输入输出示例，指明期望格式
4. Let Claude think：复杂任务让模型「一步步思考」或先列推理再给结论
5. Long context tips：长文档放开头结尾、指明要关注的部分
失败排查：只给任务不给上下文 = 模型瞎猜；不给示例 = 格式不可控；含蓄表达 = 输出偏离
适用边界：示例给太多会约束创造性，按任务类型取舍

【条目 9】Muse 等个人助理上手：最小权限 + 只连需要的服务
来源：抖音 Muse 保姆级教程、Engadget Muse 上手、DEV Community Muse for Mac 指南
适用：个人助理类产品（Muse / Meta 等）通用；企业级 AI 助理按公司安全规范
精确步骤：
1. 从官方入口确认地区和账号符合开放条件，再下载 / 打开（以官网为准）
2. 先检查数据和权限设置——是否允许对话用于训练由你决定；连接服务前看清它能读什么、能改什么
3. 只连接当前任务需要的一个服务（文件 / 日历 / 邮件按需），先 read-only 测试
4. 低风险任务试跑（「总结我下载文件夹里最近 14 天的 PDF」），确认它找得对、解析对，再逐步放开
失败排查：一上来全连 = 隐私风险与误操作风险双高；不看权限设置 = 数据被拿去训练还不知道
适用边界：地区未开放的产品先用官方渠道确认，别走非官方安装

【条目 10】Muse 使用心得：给目标不给问题，条件一次说清
来源：抖音 Muse 使用心得、Ein Verne Meta Muse 使用教程、Zapier Muse AI 指南
适用：给目标型助理用（Muse 类）；纯问答型 AI 不需要这么命令式
精确步骤：
1. 给目标不给问题：「帮我盯着这趟航班，降价告诉我」而不是「你能查航班吗」
2. 连上邮箱和日历，它才能真正替你动手
3. 长任务丢后台：你忙你的，它办完回来汇报
4. 条件一次说清：时间、预算、限制（「给我三家搬家公司报价，按价格排序」），返工最少
5. 直接语音说：想到什么说什么，它整理成任务
失败排查：只说「帮我找个搬家公司」不说「从哪搬到哪、几居室、有没有电梯、希望什么时候搬」= 来回确认耗 token
适用边界：条件过多会让助理束手束脚，关键条件（时间 / 预算）给全即可

【条目 11】不会代码的她用 Claude 做 SaaS：7 个月收第一笔 319 欧，17 个月做到 2900 欧 MRR
来源：https://soulin.co/blog/soulin-social-real-numbers
适用：有非技术主业、想用 AI 给同类独立创作者做工具的人
精确步骤：
1. 选自己所属的垂直人群做工具（她做健康疗愈内容，就给同类独立创作者做工具）
2. 每晚固定时间跟 AI 对话写代码，第 1–3 个月才做出第一版，别急着上线
3. 上线后把前 12 个朋友当测试用户：观察使用时长和功能使用率，按真实反馈重写核心模块
4. 第 4–6 个月写博客做长尾关键词，两周来 23 个陌生注册
5. 第 7 个月上线 29 欧元/月付费档，看免费用户转化
6. 开社区论坛承接客服，客服工作量下降 60%
失败排查：支付集成静默挂了 11 天，43 个用户免费用付费功能，损失约 1200 欧元；第 8 个月数据库撞限额，周二宕机 6 小时，连续修 14 小时到凌晨 4 点
结果判定：第 17 个月 MRR 2900 欧元、187 个用户（94 付费），月流失率 8.2%，每周约 10 小时维护
适用边界：前 7 个月零收入；第 10 个月一度写好关停邮件；不适合想快速暴富的人

【条目 12】认真做 18 个月的主业月入 200 美元，被晾了 18 个月的周末玩具第二个月赚了 2800 美元

结果判定：10 月收入 1400 美元、11 月 2800 美元，零营销

【条目 13】写了 3 年干净代码收入 0，故意写最丑的代码，61 天做到 5142 美元/月
来源：https://dev.to/soloproemail/how-i-went-from-0-to-5000mo-in-60-days-794
适用：会写代码、但一直困在做完美开源项目没人用循环里的开发者；给本地物流经理、房产中介、诊所这些非技术老板做工具
精确步骤：
1. 选超无聊的行业方向：给本地货运调度员做 PDF 运单自动录入，而不是做开发者工具
2. 47 小时写完原型（HTML + 原生 JS + SQLite + Stripe 链接），直接发给目标客户
3. 冷邮件拉新：第一批 83 封（76 封已读不回、4 封拒绝、3 个约电话），第 19 天现场 demo 成交第一单 149 美元/月
4. 不加功能，只问第一个客户「你为啥不推荐给同事」，修 23 个解析 edge case，加 299 美元/月多人团队档
5. 第 42–61 天加自动邮件解析（用户转发邮件即可用），签 2 家 499 美元/月的大物流商
失败排查：3 年 14 个公开仓库 0 收入——他反思干净架构就是副业 0 收入的原因；Product Hunt / HN 是虚荣陷阱：开发者最抠，会花 47 小时写脚本省 9 美元订阅费，别做开发者工具
结果判定：第 61 天 34 个付费客户、5142 美元 MRR，零广告零营销
适用边界：代码至今很乱、跑在单台服务器上偶尔崩溃靠 PM2 自动重启，34 个客户没人在意——只在乎每天早上 8 点前运单有没有被处理完
